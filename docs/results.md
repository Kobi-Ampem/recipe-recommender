# Results

Generated by `uv run python -m reciperec.report` from `runs/`. Do not edit by hand.

Protocol: each user's timeline is split oldest ~64% train, next ~16% validation, newest 20% test. Settings are chosen by validation NDCG@10; the test run then fits on train plus validation with those settings, once. Every model ranks the full catalogue with the user's own training items removed.
